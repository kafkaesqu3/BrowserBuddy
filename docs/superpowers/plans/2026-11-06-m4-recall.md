# M4 Recall and Digests Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Query captured memory with evidence-backed answers and generate recoverable
session digests through CLI and MCP.

**Architecture:** The existing backend owns retrieval, model resources, and a durable job
runner. Reconciliation discovers committed source data, including historical captures and
implicitly closed sessions. CLI/MCP adapters share authenticated HTTP contracts.

**Tech Stack:** Existing Python/FastAPI/Pydantic/SQLite/Typer/pytest/uv; proposed Pydantic AI,
FastMCP, optional sentence-transformers/sqlite-vec, direct httpx runtime dependency.

**Spec:** [M4 design](../specs/2026-11-06-m4-recall-design.md).

**Status:** Draft for approval. No tasks executed. Approve the design before product edits.
This is one milestone plan split into separately deliverable slices, not one large change.

## Global Constraints

- Preserve protocol v1, existing CLI behavior, and existing data. Append migrations after v6.
- Backend-owned workers only; no network/inference/file I/O inside database transactions.
- UTC milliseconds; [since, until) filters; explicit timezone defaults to UTC.
- Reconcile every 60 seconds in batches of 200. Inference concurrency 1; query timeout 5s.
- Search limit 20, max 100; candidate cap 200 per branch; RRF constant 60.
- Embed target 512 tokens/64 overlap; model capacity overrides target; title prefix <=32.
- Embedding batches 16; full generation identity; only completed documents are searchable.
- Retry delays 5/30/120/600/3600 seconds; fail on sixth failed execution.
- Agent limits: 8 requests, 16 tool calls, 48000 evidence chars, 90 seconds, 2000 output tokens.
- Digest link cap 50 per session; summary work cap 100 pages per runner turn.
- Digest manifests copy consumed evidence, with a stable source-derived cutoff; observation
  time never changes identity. Automatic/explicit job origin governs execution eligibility.
- No automatic model download or default remote LLM. auto_digests defaults false.
- Functions <=100 lines, complexity <=8, <=5 positional params, lines <=100 chars;
  Google-style docstrings on non-trivial public APIs. Do not add a generic plugin framework.
- Resolve stable dependency versions from official package releases at the consuming task;
  update uv.lock, justify dependencies, and record platform validation. Do not install for planning.
- Work in isolation when implementation begins; preserve unrelated working-tree changes.
- Commit subjects imperative, <=72 chars, one logical change, no AI attribution.
- Run relevant tests, ruff lint/format, and configured type checks before each commit.
  No Python type checker is currently configured; do not invent a passing type-check claim.

## Review Focus

1. Crash after source commit but before discovery: recovery must index it (Tasks 3–4).
2. Many out-of-window hits: filter before top-k, not after (Tasks 1 and 6).
3. Replayed/implicit session closure: exactly one digest per source/config (Tasks 3 and 10).
4. Malicious captured text/unknown citation: no new authority or fabricated provenance (Task 8).
5. Missing local model/unsupported SQLite extension: ingest and FTS continue (Tasks 5 and 12).

### Task 3: Durable jobs and reconciliation

**Files:** modify db.py; create jobs.py, tests/test_jobs.py, tests/test_reconciliation.py;
begin worker.py with discovery only.
**Interfaces:** define `JobKey(kind, source_id, source_version, config_id)` and JobInfo.
`JobStore(settings)` produces `enqueue(key: JobKey) -> JobInfo`,
`claim(*, now: int) -> JobInfo | None`, `retry(job_id: int) -> JobInfo`,
`finish(job_id: int, *, claim_token: str) -> bool`, and
`fail(job_id: int, *, claim_token: str, error_code: str, transient: bool, now: int) -> None`.
Enqueue accepts keyword `origin: Literal["automatic", "explicit"] = "automatic"`;
explicit requests promote an existing automatic job. JobInfo includes origin/claim_token.
`reconcile(settings: Settings, *, now: int) -> int` returns newly inserted job count.
Use one transaction per claim/state transition, never nested implicit Storage commits.

- [ ] Test real DB restart/duplicate discovery and implicit closure using start_session:
  `assert reconcile(...) == 1`; second sweep `== 0`; close/reopen before discovery and
  assert the same outcome. Seed >200 source rows. Assert disabled capabilities enqueue none,
  retry deadlines match the spec, sixth failure is terminal, stale claim cannot finish,
  and re-sweeping a failed job does not reset attempts.
  Assert disabled automation leaves automatic jobs pending, while explicit jobs can run.
- [ ] Run `uv run pytest tests/test_jobs.py tests/test_reconciliation.py -q`; confirm red.
- [ ] Append jobs migration; implement keyset sweeps and source/config fingerprints.
